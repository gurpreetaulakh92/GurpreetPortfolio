# Personal Portfolio Website – Vagrant & Linux

## About the Project

This project demonstrates the development and deployment of a personal portfolio website using a Linux virtual machine managed through Vagrant.

The development environment was configured locally using Vagrant and VMware, with Visual Studio Code connected to the virtual machine through Remote SSH.

The portfolio website was developed using HTML, CSS, and JavaScript and hosted on an Apache HTTP Server running inside the Linux virtual machine.

## Technologies Used

- **Vagrant** – Virtual machine provisioning and management
- **VMware** – Virtualization platform
- **Linux** – Web server operating system
- **Apache HTTP Server** – Hosting the portfolio website
- **Visual Studio Code** – Code development and editing
- **Remote SSH** – Remote development environment
- **HTML5** – Website structure
- **CSS3** – Website styling
- **JavaScript** – Interactive website functionality
- **Git & GitHub** – Version control and source code management

## Project Implementation

1. Created and configured a Linux virtual machine using Vagrant and VMware.
2. Established an SSH connection to the virtual machine.
3. Connected Visual Studio Code to the Linux environment using Remote SSH.
4. Installed and configured the Apache HTTP Server.
5. Created and customized the portfolio website using HTML, CSS, and JavaScript.
6. Deployed the website files to the Apache document root (`/var/www/html/`).
7. Configured file permissions for website development and management.
8. Tested the website locally through the web browser.
9. Prepared the project for version control and hosting on GitHub.

## Project Objectives

- Gain hands-on experience with Linux administration.
- Understand virtual machine provisioning using Vagrant.
- Practice remote development using Visual Studio Code and SSH.
- Learn Apache web server configuration and website deployment.
- Develop practical skills in web development and Git-based version control.

## Key Learning Outcomes

This project provided practical experience in virtualization, Linux server administration, SSH connectivity, web server management, troubleshooting file permissions, and deploying a website in a virtualized development environment.
